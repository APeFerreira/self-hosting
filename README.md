# self-hosting

A monorepo for aggregating my steps onto self-hosting. Feel free to contribute!

## Installation order

[Unbound](./unbound/README.md) must be installed, started, and validated before
any other service. It provides the recursive DNS foundation that the rest of
the self-hosted environment can depend on.
